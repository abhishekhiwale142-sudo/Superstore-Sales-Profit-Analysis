# Superstore Sales & Profit Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Superstore sales dataset to understand sales, profit, discounts, product categories, regions, and customer segments.

## Objective

The main objective of this project is to identify important business patterns and relationships in the sales and profit data.

## Dataset

The dataset contains information about:

- Order Date
- Ship Mode
- Segment
- Region
- Category
- Sub-Category
- City
- Quantity
- Discount
- Sales
- Profit

## Data Analysis

The analysis includes:

- Data understanding
- Data cleaning
- Missing value handling
- Duplicate removal
- Numerical variable analysis
- Categorical variable analysis
- Sales and profit analysis
- Discount and profit analysis
- Profit margin analysis
- Region and category analysis
- Correlation analysis

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights

- West generated the highest total sales, while East generated the highest total profit.
- Technology was the highest-performing category in terms of total sales and total profit.
- Furniture had the lowest average profit among the categories.
- Phones generated the highest total profit among the sub-categories, while Tables generated the lowest.
- Higher discounts were associated with lower profit margins.
- East + Technology generated the highest profit among Region–Category combinations.
- Consumer + Technology showed strong performance among Segment–Category combinations.

## Project Files

- `Superstore_Sales_Profit_Analysis.ipynb` — Complete EDA notebook
- `Sample_Superstore.csv` — Dataset used for analysis

## Conclusion

The analysis provided useful insights into sales, profit, discounts, regions, categories, sub-categories, and customer segments. The findings highlight the importance of analyzing profitability along with sales revenue and understanding how discounts are associated with profit margins.
